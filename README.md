# UserFlow

UserFlow est une application web permettant de générer rapidement des comptes utilisateurs, identifiants et mots de passe pour les équipes informatiques.

L'objectif est de simplifier et standardiser les procédures de création de comptes tout en réduisant les erreurs et le temps passé sur les tâches répétitives.

**UserFlow est né d'un besoin concret rencontré en entreprise : réduire le temps nécessaire à la création de comptes utilisateurs tout en standardisant les procédures informatiques.**

## 🚀 Démonstration

**Tester UserFlow :**

https://userflow-demo.jg-systems.fr/

⚠️ Environnement de démonstration réinitialisé automatiquement chaque nuit.

## Fonctionnalités

- Génération automatique d'identifiants
- Génération de mots de passe sécurisés
- Modèles d'identifiants personnalisables
- Export Excel pour création compte Microsoft 365
- Gestion d'applications et services internes
- Association de scripts aux applications
- Interface simple et intuitive
- Gestion des administrateurs

## Cas d'utilisation

UserFlow peut être utilisé pour :

- Création de comptes Microsoft 365
- Création de comptes Active Directory
- Création de comptes métiers
- Création de dossiers utilisateurs
- Standardisation des procédures d'arrivée de collaborateurs
- Génération de fiches de comptes (pour l'utilisateur final)

## Installation

### Prérequis

- PHP 8.1 ou supérieur
- MySQL ou MariaDB
- Serveur Web Apache ou Nginx

### Installation

1. Télécharger le projet
2. Mettre les fichier sur votre serveur web
3. Créer une Base de données
4. Modifier le fichier /includes/config.php
