# Security Policy

## Supported Versions

La branche principale du projet est actuellement maintenue et reçoit les correctifs de sécurité.

| Version            | Support |
| ------------------ | ------- |
| Main               | ✅       |
| Anciennes versions | ❌       |

## Reporting a Vulnerability

Si vous découvrez une vulnérabilité de sécurité dans UserFlow, merci de ne pas ouvrir d'issue publique.

Veuillez signaler le problème par e-mail :

[contact@jg-systems.fr](mailto:contact@jg-systems.fr)

Merci d'inclure dans votre message :

* Description de la vulnérabilité
* Étapes permettant de reproduire le problème
* Impact potentiel
* Captures d'écran ou preuves si disponibles

Une réponse sera apportée dans les meilleurs délais.

## Security Best Practices

Lors du déploiement de UserFlow, il est recommandé de :

* Utiliser HTTPS
* Mettre à jour régulièrement PHP et la base de données
* Utiliser des mots de passe forts
* Restreindre l'accès aux interfaces d'administration
* Ne jamais exposer les fichiers de configuration contenant des identifiants ou mots de passe
* Réaliser des sauvegardes régulières

## Responsible Disclosure

Merci de signaler les vulnérabilités de manière responsable afin de laisser le temps nécessaire à leur correction avant toute divulgation publique.
